# MOTORYAT V2 DESIGN LAB V1

Bu paket mevcut V319.9 kodundan bağımsız, temiz bir Next.js prototipidir.

- Supabase bağlantısı YOK.
- Harici görsel/hotlink YOK.
- Tasarım geliştirme sırasında Supabase kota tüketmez.
- Satılık: YachtWorld tarzı filtreli katalog yaklaşımı.
- Kiralık: destinasyon/deneyim odaklı charter yaklaşımı.
- Ürünler: denizcilik e-ticaret kategorileri + OEM/parça kodu araması.
- Mağazalar: beyaz, sade, premium mini-site yaklaşımı.
- Satıcı paneli: sosyal medya kadar basit yönetim mantığı.
